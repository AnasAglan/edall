# إكمال النقطتين المتبقيتين + اختبار الكل

## 4. رفع ملف PDF ثانٍ يمسح الأول
عند اختيار ملفات جديدة تُستبدل قائمة الرفع بالكامل. الإصلاح:
- إضافة الملفات الجديدة إلى القائمة بدل استبدالها، مع منع تكرار نفس الملف.
- عرض قائمة تراكمية لكل الملفات (المرفوعة والجارية) مع شريط تقدّم وزر ✕ لكل ملف يحذفه من التخزين.
- حفظ كل الملفات بترتيب صحيح عند إنشاء أو تعديل المحاضرة.

## 6. وسم "مجانية / مدفوعة" بجانب كل محاضرة
- داخل صفحة الكورس وقوائم إدارة المحاضرات: وسم أخضر "مجانية" أو برتقالي "مدفوعة" بجانب اسم كل محاضرة.
- في الكورسات المجانية تظهر كل المحاضرات "مجانية". يدعم العربية والإنجليزية.

## اختبار
تجربة فعلية في المتصفح: إنشاء كورس كمدرس، إضافة ملفي PDF متتاليين، ظهور الوسوم، ملء الشاشة مع العلامة المائية، والرجوع للصفحة السابقة بعد إغلاق الكورس.

## التفاصيل التقنية
- الملف: `public/ed_master.html` فقط.
- `startPdfPreUploads`: `_activePdfUploads.push(...)` بدل `= files.map(...)`، وإعادة رسم القائمة من المصفوفة كاملة، وتصفير المصفوفة فقط عند فتح نافذة جديدة أو الحفظ.
- الوسوم في `showCourseDetails` وقوائم الإدارة، بالاعتماد على `course.price` و`lesson.isFree`.
