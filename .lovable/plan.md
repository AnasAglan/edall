# تغيير اسم المنصة إلى ED ALL

## التنفيذ
- استبدال الاسم الظاهر `ED MASTER` بـ `ED ALL` في الصفحة الرئيسية، صفحة الدخول، الشريط العلوي، والتذييل.
- تحديث عنوان المتصفح وبيانات المشاركة الاجتماعية إلى الاسم الجديد.
- تحديث اسم وعنوان تكامل أدوات المنصة الظاهر للمستخدم، مع إبقاء المسارات وأسماء الملفات الحالية دون تغيير حتى لا تتعطل الروابط.
- فحص الصفحة بعد التعديل والتأكد من نجاح البناء وعدم بقاء الاسم القديم في الواجهات.
