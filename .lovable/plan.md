# خطة التنفيذ

## 1. تعديل صفحة تواصل التليجرام (للأدمن)
- إضافة أيقونة قلم في أعلى نافذة التليجرام (تظهر فقط للأدمن).
- عند الضغط: نافذة وسطية بها:
  - رفع صورة QR جديدة → تُرفع إلى bucket `avatars` (أو bucket جديد `site-assets`) وتحديث الرابط.
  - حقل لتعديل رابط الشات (بدل الرابط الثابت `t.me/anasaglan`).
- تخزين الإعدادات في جدول جديد `site_settings` (key/value) أو استخدام صف واحد `telegram_config`.

## 2. أسعار الكورسات + الشراء من المحفظة
### قاعدة البيانات
- إضافة عمود `price numeric(12,2) default 0 NOT NULL` إلى جدول `courses` (0 = مجاني).
- تعديل RPC جديد `purchase_course(_course_id uuid)`:
  - يتحقق من التسجيل المسبق.
  - إذا `price = 0` → إضافة enrollment مباشرة.
  - إذا `price > 0` → يتحقق من رصيد المحفظة، يخصم المبلغ، يضيف صفاً في `wallet_transactions` (type = `purchase`, amount سالب، note = اسم الكورس)، يضيف enrollment، يرسل notification.
  - يرفع خطأ `INSUFFICIENT_BALANCE` إذا الرصيد لا يكفي.

### الواجهة
- **صفحة الكورس / كارت الكورس:** إظهار السعر بجانب زر "انضم" (أو "مجاني").
- عند الضغط على "انضم" لكورس مدفوع: استدعاء `purchase_course`.
  - نجاح → toast + فتح الكورس.
  - فشل بسبب الرصيد → نافذة وسطية: "رصيدك لا يكفي لشراء الكورس" + زر "الذهاب إلى المحفظة" (يوجه إلى `#/wallet`).
- **صفحة إنشاء/تعديل الكورس** (للمدرس والأدمن): إضافة حقل "السعر" + checkbox "مجاني" (يجعل السعر 0).

## 3. سحب الرصيد من الأدمن
- في صفحة `#/wallet/admin-topup`: بجانب كل مستخدم زر ➖ إضافي.
- عند الضغط: نفس modal الشحن لكن يستخدم مبلغاً سالباً عبر نفس `admin_credit_wallet` (يدعم مبالغ سالبة بالفعل).
- تحقق أن الرصيد لا يصبح سالباً (تعديل الدالة لرفع خطأ إذا نتج رصيد سالب).

## 4. محاضرات مجانية داخل كورس مدفوع
### قاعدة البيانات
- إضافة عمود `is_free boolean default false NOT NULL` إلى جدول `lessons`.
- تعديل RLS/الاستعلامات: المستخدم غير المشترك يرى قائمة المحاضرات دائماً، لكن محتوى المحاضرة (فيديو/PDF/امتحان) يفتح فقط إذا:
  - `is_free = true`، أو
  - المستخدم مشترك في الكورس، أو
  - سعر الكورس = 0.

### الواجهة
- **صفحة إضافة/تعديل المحاضرة:** checkbox "محاضرة مجانية" (يظهر فقط إذا كان الكورس مدفوعاً).
- **صفحة عرض الكورس:** إظهار كل المحاضرات؛ المحاضرات المقفلة عليها أيقونة قفل ولا تفتح، ماعدا المجانية.

## 5. معرّف مستخدم من 5 خانات
### قاعدة البيانات
- إضافة عمود `public_id text UNIQUE` إلى جدول `profiles`.
- Function `generate_public_id()` تولد رقماً عشوائياً من 5 خانات (10000-99999) وتضمن التفرد.
- Backfill لكل المستخدمين الحاليين.
- تعديل `setup_new_user` لتوليد `public_id` لكل مستخدم جديد.

### الواجهة
- عرض `public_id` في صفحة الملف الشخصي (للجميع: طالب/مدرس/أدمن).

## 6. الترابط والاختبار
- تحديث الترجمات (عربي/إنجليزي) لكل النصوص الجديدة.
- التأكد من تحديث `types.ts` تلقائياً بعد الـ migrations.
- اختبار السيناريوهات:
  1. أدمن يعدل صورة/رابط التليجرام → المستخدمون يرون التحديث.
  2. مدرس ينشئ كورساً بسعر 50 → طالب برصيد 30 يحاول الشراء → نافذة "الرصيد لا يكفي".
  3. أدمن يشحن المستخدم 100 → الطالب يشتري الكورس → الرصيد يصبح 80 والعملية مسجلة.
  4. أدمن يسحب من مستخدم عبر ➖ → الرصيد ينقص والعملية مسجلة.
  5. مدرس يجعل محاضرة مجانية داخل كورس مدفوع → غير مشترك يفتحها فقط، الباقي مقفل.
  6. كل مستخدم لديه public_id فريد من 5 أرقام في ملفه.
